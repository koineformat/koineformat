# own-docs — a koine repo

This directory is a **koine repo**: ordinary files plus `.koine/` sidecars.
It is the S1 pilot of the koine standard (the smallest real instance, floors 0–2),
and it carries a slice of this project's own docs: what a koine repo is, one real
metric definition, and the nine ratified family decisions as data.

Everything here is consumable without any tooling — the files are the format.
